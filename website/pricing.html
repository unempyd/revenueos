How the licence key gets to your install

  1. Choose a tier above — you're sent to a Stripe Checkout page for that subscription.
  2. Stripe confirms the subscription and calls RevenueOS Inc.'s webhook.
  3. We sign a licence key for your account and email it to the address on the subscription.
  4. Run revenueos license install <key> on your install — revenueos license show confirms the tier.
