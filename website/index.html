What happens after you connect

Day by day, not a feature list.

Day 0 — Connect

Give it your website. It reads the site, fills in your business profile and labels every guess. Add Stripe, your site's repo or WordPress, Google or Meta when you want more done.

Day 0 — Audit

Every page crawled, the homepage read for tappable phones, LocalBusiness schema, canonical, titles, descriptions, sitemap; ad exports or connected accounts run through the 414-control catalogue. Findings land on TODAY with Approve / Execute / Ignore.

Days 1–7 — First fixes ship

Each approved fix is deployed by RevenueOS itself where it can (git-hosted sites, WordPress) or handed to you as an exact change. Then it re-checks the live page and writes before → after next to the action.

Every week — Re-check and next action

Workers run on a schedule, prospects with live ad spend are found from public data, drafts wait for your read, wasting campaigns are queued to pause. revenueos next ranks what to do from what actually worked.

When you agree — Pay

Nothing is charged until RESULTS shows a measured change you approved. Then 14 more days free, then $99/month to keep it running continuously. One-shot runs and the panel never lock.

Install

Run it yourself, today

No account required for Community. Install it, connect your business.

# install
uvx revenueos demo https://yoursite.com   # nothing installed, one command
pip install revenueos   # or: uv tool install revenueos — to keep it

# connect your business and turn it on
revenueos init                     # the questionnaire → company-context/ + revenueos.yaml
revenueos run all                  # run every worker once
revenueos today                    # the brief
revenueos serve                    # the control panel: http://127.0.0.1:8791

From source: git clone https://github.com/unempyd/revenueos && cd revenueos && uv sync && (cd orchestrator && npm install), then run the same commands with uv run in front. Optional: ANTHROPIC_API_KEY (or ant auth login) turns on the LLM paths — relevance gating, personalised openers, running skills — without it every worker still runs deterministically. SMTP_PASSWORD + smtp.host in revenueos.yaml enables real sending; REVENUEOS_DRY_RUN=1 writes emails to data/outputs/ instead. Already have a licence key? Run revenueos license install <key>.

Honesty, by design

Built in the open

RevenueOS is MIT-licensed. It includes permissively-licensed open-source components, with full attribution for every one of them — upstream repository, commit and licence — recorded in NOTICE.md. RevenueOS never bundles copyleft code into the licensed product; where a copyleft component is used at all, it runs as an external service across a process boundary, not inside the product itself.

This isn't a from-scratch rewrite dressed up as one — it's glue code, business context, approval and measurement logic built new, over components whose licences allow exactly this kind of reuse.

Questions

The things people ask first.

Do I have to give you access to anything?

No. The audit reads your public web presence only — the same pages anyone can load. Connectors exist for Google, Meta, Stripe and others, but they are opt-in, stay read-only until you explicitly allow changes, and the install runs on your machine.

What stops it emailing my customers by mistake?

Workers are structurally incapable of sending. Only an action you approve can act, and sending is additionally bounded by a daily cap, a suppression list, a List-Unsubscribe header and reply-STOP handling.

Is there a free tier, or is it a trial?

Community is free permanently and is not a trial — every worker, the full skill catalogue, and the control panel. Paid tiers add continuous operation via the orchestrator; you always own the install either way.

How many customers do you have?

None yet. RevenueOS went public on 2026-09-12 and has zero paying customers, zero stars and $0 revenue. The proof page is a real run against a real company’s public site, not a case study, and there are no testimonials on this page because there is nobody to quote.

What does it not do?

Live ad-platform ingestion is CSV export only. Reddit monitoring is not built. Multi-brand and multi-user are single-workspace today. The authority-comparison endpoint returns HTTP 403 and is reported as unavailable rather than guessed.
